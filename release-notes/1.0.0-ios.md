# KbpsLive 1.0.0

## Store Summary
Listen to KBPS Live, explore the schedule, and find help in the app guide.

## New Features
- Listen live and view recently played songs.
- Explore the show schedule, news, interviews, and song requests.
- Open the App Guide and What's New from Settings.

## Bug Fixes
- Improved the App Guide and What's New screens with clear navigation.
- Removed the duplicate custom Live Activity in favor of the system Now Playing controls on the Lock Screen and Dynamic Island.
- Reduced artwork and playback display flicker by avoiding repeated Now Playing resets.
- Reduced home-screen pause latency so playback UI clears immediately when stopping.
- Improved iOS now-playing handoff so active Kbps playback metadata stays prioritized.
- Restored iOS tab bar compact-on-scroll behavior on supported iOS versions.
- Removed the startup slide transition before landing on the Live home tab.

## Full Release Notes
Find the App Guide and What's New in Settings whenever you need them.

KbpsLive 1.0.0 brings live listening, recently played songs, and the station schedule together.
